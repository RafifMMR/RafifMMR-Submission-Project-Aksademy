# Portfolio — Rafif Frontend Developer & UI/UX Designer

RafifMMR-Submission-Project-Aksademy

Selamat datang di **Dark Portfolio**!  
Ini adalah proyek tugas yang menampilkan portofolio seorang Frontend Developer & UI/UX Designer dengan pendekatan **modern brutalism**, clean UI, dan integrasi stack terbaru.

---

## 🌟 Fitur Utama

- **Responsif & Clean Layout**  
  Menggunakan Tailwind CSS dan Google Font _Space Grotesk_ untuk tampilan modern, minimalis, dan profesional.

- **Smooth Scroll & Navigation**  
  Navbar dengan scroll smooth antar section: Home, About, Contact.

- **Call-to-Action (CTA)**  
  Tombol **Work with Me** dan **Chat with me** yang langsung membuka WhatsApp.

- **Scroll-to-Top Button**  
  Muncul saat scroll ke bawah >300px dengan animasi fade dan scale halus.

- **Social Media Footer**  
  Icon Instagram, LinkedIn, Github dengan hover effect.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Tailwind CSS
- **Design & UX:** Figma, modern brutalism approach
- **Fonts:** Space Grotesk (Google Fonts)
- **Features:** Smooth scroll, hover & active effects, responsive layout
